URL SHORTENER

Node Js Express PostgreSQL

I developed a production-ready URL Shortener Backend using Node.js, Express.js, PostgreSQL, and Drizzle ORM that allows users to securely generate and manage shortened URLs with JWT-based authentication and salted password hashing. The project includes RESTful APIs for user registration, login, URL shortening, and redirection, along with relational database design using PostgreSQL foreign key relationships. I also integrated Docker for containerized backend and database setup, used Zod for request validation, and NanoID for generating unique short codes, making the system scalable, secure, and deployment-ready.
